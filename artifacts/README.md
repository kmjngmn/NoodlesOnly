# 화면 확인용 캡처

이 폴더의 PNG는 **실제 스터디원 기록이 아닌 임시 예시 데이터**로 촬영했습니다.

- 예시 날짜: 2026년 11월 8일 (한국 시간)
- 별도 임시 SQLite 데이터베이스의 가상 스터디원 4명 사용
- 모바일 360~390px 및 데스크톱 1100px 화면
- 개인 인증 진행률, 벌금 안내, 전체 인증 현황, 주간 정산을 확인하기 위한 자료
- 실제 앱 데이터와 분리되어 있으며 **공개 배포나 운영 중인 서비스의 화면이 아닙니다.**

`mobile-home.png`, `desktop-home.png`: 개인 인증 및 지난주 벌금 안내.
`mobile-overview.png`, `desktop-overview.png`: 스터디원별 주간 인증·미인증·휴식 표시.
`mobile-settlement.png`, `desktop-settlement.png`: 지난주 정산과 운영자의 납부 확인.
